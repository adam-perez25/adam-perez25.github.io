# Portfolio

My personal portfolio site: who I am, my projects and how to contact me.

It's plain HTML and CSS, with no build step:

- `index.html`: all the content (projects, about, contact)
- `styles.css`: the design (colors are at the top, with a dark mode version)
- `favicon.svg`: the browser-tab icon

## See it locally

Double-click `index.html`, or open it in any browser.

## Publish it

The site is hosted with GitHub Pages. The repo is named `adam-perez25.github.io`, so GitHub publishes it at
https://adam-perez25.github.io automatically on every push to `main`.

## Add a project

Copy one of the `<article class="card">` blocks in `index.html`, change the title, tag, description,
tech list and links, and push.
